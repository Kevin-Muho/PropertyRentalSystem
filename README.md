# Property Rental System | Software Modeling & Design Project

A Software Modeling and Design project focused on designing a Property Rental System using UML diagrams, object-oriented analysis, and software design principles.
This project models a real-world rental platform where tenants, property owners, administrators, managers, financiers, and HR staff interact through a centralized rental management system.

The project demonstrates how software modeling techniques and object-oriented design concepts can be used to structure and analyze a complex property rental platform.

---

# Overview

This project implements the full software analysis and design of a property rental management platform. The system focuses on modeling user interactions, workflows, data structures, and system processes involved in property rentals.

The system allows management of:

* tenants and property owners
* administrators, managers, financiers, and HR staff
* rental properties and listings
* booking and rental requests
* rental payments and refunds
* complaints and issue management
* user authentication and communication
* notifications and reporting
* property availability and booking history

The goal of the project is to demonstrate how software modeling and object-oriented analysis can be used to design a scalable and structured property rental management system.

# Software Modeling & Object-Oriented Design

The system follows fundamental OOP principles:

## Encapsulation

Sensitive information such as user credentials, rental details, and payment records are protected inside classes.

## Inheritance

Classes extend base classes to create specialized property and user functionality.

## Abstraction

Complex rental operations and workflows are separated into different system models and processes.

## Polymorphism

Objects can perform different behaviors depending on their role and type.

# Project Structure

Main system components included in the project:

* **User** – abstract actor inherited by all system roles
* **Tenant** – searches and rents properties
* **PropertyOwner** – manages property listings and rental requests
* **Administrator** – supervises and manages the platform
* **Manager** – oversees operations and complaints
* **Financier** – handles payment and refund operations
* **HR** – manages user complaints and notifications
* **Property** – stores rental property information
* **Booking** – manages booking operations and rental status
* **RentalRequest** – handles rental requests between tenants and owners
* **Payment** – processes payment transactions
* **Review** – stores tenant ratings and reviews
* **Complaint** – manages complaints and issue resolution
* **Notification** – handles alerts and communication between users
